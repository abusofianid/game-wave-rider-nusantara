# Wave Rider Nusantara (Web)

The React + Vite version of Wave Rider Nusantara. Play it live at [waveridernusantara.vercel.app](https://waveridernusantara.vercel.app/).

## Run locally

Requires Node.js.

```bash
npm install
npm run dev
```

## Scripts

| Command | What it does |
| :--- | :--- |
| `npm run dev` | Start the dev server |
| `npm run build` | Build for production into `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
