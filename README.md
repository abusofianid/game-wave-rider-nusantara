### 🚀 How to Run

**Clone the repository**
```bash
git clone https://github.com/abusofianid/game-wave-rider-nusantara.git
cd game-wave-rider-nusantara
```

#### ▶️ Running the Web Version (React)
**Make sure Node.js is installed.**
```bash
npm install
npm run dev
```

#### ▶️ Running the Desktop Version (Python)
**Make sure `uv` is installed** (get it from [docs.astral.sh/uv](https://docs.astral.sh/uv/getting-started/installation/)).
```bash
# Create and activate virtual environment
uv venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies and run
uv pip install -r requirements.txt
uv run main.py
```
*Replace `main.py` with the actual entry point file of your Python game if different.*
